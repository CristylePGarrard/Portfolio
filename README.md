## Professional Data Engineering

One of the projects that shaped my career involved processing large volumes of vendor flat files for a production application.

The workflow had to:

- identify different file formats from source records
- validate dates, required fields, numeric values, and allowed codes
- reject individual bad records without losing an entire file
- normalize valid data
- produce application-ready output
- notify process owners when processing completed

I built the processing application in **Python**, using **SQL** for validation and data work. The process handled **millions of records daily**.

This portfolio cannot contain the proprietary production code, but the problem-solving approach behind it influences many of the projects in this repository.
