The approach

A practical workflow, not just a notebook full of charts.

The project separates reusable data operations from exploratory analysis, so the work can be inspected, repeated, and extended.

01 / PREPARE

Inspect and combine

Review columns, types, missing values, and duplicates; join related tables and standardize the dataset for analysis.

02 / INVESTIGATE

Explore the market

Use summaries and visualizations to examine service prices, delivery timelines, common values, and data-quality questions.

03 / INTERPRET

Explore listing language

Use a separate notebook to look at recurring words and terms in gig text. This is exploratory text analysis, not a trained NLP model.

What this demonstrates

Make the data trustworthy enough to ask better questions.

The useful part of analysis starts before the chart: understanding source fields, managing missingness, combining related data, and being clear about what the results can—and cannot—tell us.

Skills in practice

  • Python and pandas data workflows
  • Loading, cleaning, joining, and normalizing tables
  • Missing-value and duplicate checks
  • Exploratory data analysis and summary statistics
  • Matplotlib / Seaborn visualizations
  • Basic keyword frequency and text exploration

Project structure

  • notebooks/ — exploratory analysis and NLP notebooks
  • src/ — reusable loading, cleaning, ETL, quality, and analysis helpers
  • data/ — separate raw and processed data areas
  • portfolio/ — screenshots and selected chart exports
The notebooks are exploratory, and the analysis should be interpreted in the context of the data available. This is a portfolio project in progress—not a claim of a production market-intelligence platform.
